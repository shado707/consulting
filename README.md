# Software Engineering & Automation Consulting — Razorpay-Ready Static Site

This is a production-ready, Razorpay & RBI compliant static website representing an independent software engineering and automation consulting business.

## Site Structure

- `index.html`: Main landing page with Services (APIs, Data Pipelines, Database Automation), Pricing Breakdown, About, and Contact details.
- `terms.html`: Terms & Conditions covering scope of services, intellectual property ownership, milestone payments, and governing law.
- `privacy.html`: Privacy Policy detailing data handling, zero payment credential storage, and client confidentiality.
- `refund.html`: Comprehensive Cancellation & Refund Policy specifying milestone review rules, 7-day refund request window, and 5-7 day banking processing timelines.
- `styles.css`: Dark-mode design system with DM Sans and Space Grotesk typography, responsive mobile grids, and sleek UI.

## How to Deploy Free on GitHub Pages (Takes 2 Minutes)

1. Create a new public repository on GitHub (e.g. `consulting` or `portfolio`).
2. Upload all 5 files (`index.html`, `terms.html`, `privacy.html`, `refund.html`, `styles.css`) directly into the repository root.
3. In GitHub, go to **Settings** → **Pages** (in the left sidebar).
4. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main** (or **master**) / `/(root)`
   - Click **Save**.
5. Wait 60–90 seconds for GitHub to build the site.
6. Your live URL will be:
   `https://<your-github-username>.github.io/<repo-name>/`
7. Copy this URL and paste it into the Razorpay onboarding field.
